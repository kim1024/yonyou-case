## 5. 限额耗尽提示 — 错误处理

### 5.1 Toast 通知（管理后台内）

当管理员在后台触发了限额耗尽的模型请求时：

```
┌─────────────────────────────────────────────┐
│  ⛔  模型「主配置」今日 Token 限额已耗尽       │
│     (1,000,000 / 1,000,000)                  │
│     新请求已被拒绝，限额将在明日 00:00 重置。   │
└─────────────────────────────────────────────┘
```

| 元素 | 规格 |
|------|------|
| 类型 | `toast-error` 样式（红色渐变背景） |
| 图标 | `X` 或 `Ban`（禁止图标） |
| 标题 | 模型名称 + 已耗尽 |
| 详情 | 用量数值 + 重置时间提示 |
| 持续时间 | 5000ms（比普通 toast 长） |

### 5.2 API 错误响应格式

```json
{
  "detail": "TOKEN_QUOTA_EXCEEDED",
  "message": "模型「主配置」今日 Token 限额已耗尽 (1,000,000/1,000,000)",
  "model_name": "主配置",
  "daily_limit": 1000000,
  "used_today": 1000000,
  "reset_at": "2026-04-28T00:00:00+08:00"
}
```

### 5.3 前端错误拦截

```typescript
// http.ts 拦截器中处理
if (error.response?.data?.detail === 'TOKEN_QUOTA_EXCEEDED') {
  const { model_name, daily_limit, used_today, reset_at } = error.response.data
  showToast(
    `模型「${model_name}」今日 Token 限额已耗尽 (${formatTokenNumber(used_today)}/${formatTokenNumber(daily_limit)})，限额将在 ${formatTime(reset_at)} 重置`,
    'error'
  )
}
```

### 5.4 表格中的视觉提示

当限额耗尽时，模型配置表格中对应行的"每日限额"列显示：

```
  ┌──────────────┐
  │  已耗尽  ⛔   │  bg-red-50 text-red-600 border border-red-200 rounded-md px-2 py-0.5
  │  1M / 1M     │  text-[10px] text-red-400
  └──────────────┘
```

同时该行添加左侧红色边框（类似 `llm-row--active` 的绿色边框）：

```css
.llm-row--exhausted {
  background-color: rgba(239, 68, 68, 0.03) !important;
  border-left: 3px solid #EF4444;
}
```

## 8. 交互流程

### 8.1 设置限额流程

```
用户点击"编辑"模型配置
  → 弹窗打开，显示当前 daily_token_limit
  → 用户输入新限额（或点击快捷按钮）
  → 点击"保存"
  → API 更新配置
  → 表格刷新，显示新的限额进度
  → Toast: "配置已保存，限额已更新"
```

### 8.2 限额耗尽流程

```
用户发起 LLM 请求
  → 后端检查 daily_token_used >= daily_token_limit
  → 如果耗尽：返回 429 + TOKEN_QUOTA_EXCEEDED
  → 前端拦截器显示红色 Toast
  → 表格中该模型行显示"已耗尽"状态
  → 次日 00:00 自动重置（后端定时任务）
```

### 8.3 链路限额流程

```
主模型设置限额 = 1M
  → 链路中所有模型（主 + 备用）共享 1M 额度
  → 每次 LLM 调用，无论哪个模型响应，都累计到同一计数器
  → 链路抽屉显示累计用量
  → 耗尽时，整条链路拒绝请求（不会 fallback 到备用模型）
```

## 11. 实现优先级

1. **P0 — 核心功能**
   - 模型配置表格增加限额列（展示 + 进度条）
   - 模型创建/编辑弹窗增加限额输入
   - 后端限额检查 + 错误响应
   - 前端错误拦截 + Toast 提示

2. **P1 — 增强体验**
   - Token 统计 Tab 限额概览卡片
   - 链路抽屉限额展示
   - 限额耗尽行样式

3. **P2 — 锦上添花**
   - 快捷按钮（100K/500K/1M/5M）
   - 限额重置倒计时
   - 限额用量历史趋势
