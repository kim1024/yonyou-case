# Code Review Findings

持续更新的审查记录。当前优先级按 `High -> Medium -> Low` 排列。

## High

### 1. 链路运行状态只存在于进程内存，多进程/多实例下会出现路由不一致

- 位置: `backend/app/services/llm_chain_manager.py:26-35`, `backend/app/services/llm_chain_manager.py:41-67`, `backend/app/services/llm_chain_manager.py:117-188`
- 问题: 链路当前活跃模型、失败计数、冷却时间都保存在 `_states` 这个进程内字典里。只要部署为多个 Uvicorn/Gunicorn worker、多个容器副本，或发生进程重启，不同实例看到的活跃模型就会不一致。
- 影响: 主备切换结果可能在不同请求之间漂移，表现为管理后台显示一个状态、实际请求命中另一个状态，甚至同一条链路在不同 worker 上各自维护一份失败计数。
- 建议: 把链路运行态下沉到共享存储，至少使用数据库行锁或 Redis 之类的共享状态层，避免把路由真值绑在单进程内存里。

## Medium

### 2. 访问日志中间件在请求链路上同步写库和写文件，容易成为性能瓶颈

- 位置: `backend/app/middleware/analytics_middleware.py:14-77`
- 问题: 每个非管理后台 API 请求都会在响应后同步执行一次数据库 `commit`，再追加一份 JSONL 备份文件。这里没有队列、批处理或失败降级。
- 影响: 高并发时，这个中间件会把 I/O 延迟直接加到用户请求上；数据库慢、磁盘慢或文件系统抖动时，整个 API 的尾延迟会被放大。
- 建议: 改成异步批量落盘，或者至少将访问日志写入独立队列/后台任务，避免阻塞主请求路径。

### 3. 课程生成接口把外部 LLM 调用、数据库写入和重试逻辑全部串在单个同步请求中

- 位置: `backend/app/routers/wizard.py:338-460`
- 问题: 生成接口在一个同步请求里完成企业查询、模板拼装、Lllm 调用、故障切换、配额检查、Token 记录和方案落库。外部请求是串行执行的，失败重试也是同步等待。
- 影响: 单次生成耗时长时会占用工作线程，吞吐会随 LLM 延迟线性下降。故障链路越长，请求耗时越不可控。
- 建议: 把生成过程拆成更清晰的服务层，外部 LLM 调用最好走异步任务或至少把重试、降级、持久化拆开，降低请求线程占用。

### 4. 限流中间件信任 `X-Forwarded-For`，客户端可伪造来源 IP 绕过限流

- 位置: `backend/app/middleware/rate_limit.py:171-179`
- 问题: `_get_client_ip()` 直接读取 `X-Forwarded-For`，没有任何可信代理校验或 `TrustedHost` / 代理白名单约束。
- 影响: 只要请求能直达应用，攻击者就可以伪造 `X-Forwarded-For` 来规避基于 IP 的滑动窗口限流；即便在 NAT 场景下，多个真实用户也会共享同一个限流维度。
- 建议: 只在明确的可信代理后面信任转发头；否则应优先使用连接对端地址，或用网关层完成限流。

### 4. 前端大模型管理页过于臃肿，状态和展示逻辑高度耦合

- 位置: `frontend/src/views/LlmView.vue:1-3512`
- 问题: 一个单文件组件同时承担模型配置 CRUD、链路管理、Token 统计、提示词模板、限额展示等多种职责。
- 影响: 页面状态语义很容易被混用，最近的链路状态问题就是这种耦合的直接表现；后续修复和回归成本都会偏高。
- 建议: 拆成更小的视图组件和 composable，把“链路运行态计算”“表格展示”“抽屉编辑”“统计面板”分离，减少交叉影响。

## Low

### 6. 登录 token 生命周期虽已支持配置，但仍在导入时固定为进程常量

- 位置: `backend/app/services/auth_service.py:21-41`, `backend/app/config.py:46-123`
- 问题: `ACCESS_TOKEN_EXPIRE_HOURS` 在模块导入时读取一次 `settings.admin.token_expire_hours`，后续如果配置热更新，已加载进程不会跟着变。
- 影响: 如果预期后台配置可运行时生效，这里会产生认知偏差；目前更像“启动时配置”而不是“实时配置”。
- 建议: 如果要保留热更新语义，应该在创建 token 时动态读取；如果只允许启动时生效，需要在文档里明确。
