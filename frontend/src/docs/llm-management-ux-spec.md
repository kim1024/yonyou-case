# 大模型管理页面 — UX 设计方案

> 版本: v1.0 | 日期: 2026-04-23 | 作者: UX Designer

---

## 一、信息架构

```
/admin/llm
  ├── [页面标题区] 大模型管理 + 描述
  ├── [Tab 切换栏]
  │   ├── Tab 1: 模型配置
  │   ├── Tab 2: Token 统计
  │   └── Tab 3: 提示词模板
  │
  ├── [Tab 1] 模型配置
  │   ├── 操作区: 新增配置按钮
  │   ├── 表格区: 模型配置列表
  │   │   ├── 列: 配置名称 | 模型 | Base URL | API Key (掩码) | Temperature | Max Tokens | 状态(启用/禁用) | 当前使用 | 操作
  │   ├── 分页
  │   └── 弹窗: 新增/编辑模型配置
  │
  ├── [Tab 2] Token 统计
  │   ├── 统计卡片区 (4 张 gradient-card)
  │   │   ├── 总消耗 Token 数
  │   │   ├── 今日消耗
  │   │   ├── 总调用次数
  │   │   └── 平均每次调用 Token 数
  │   ├── 趋势图区: 按天 Token 消耗折线图 (7天/30天切换)
  │   └── 分布图区: 按模型饼图或柱状图
  │
  └── [Tab 3] 提示词模板
      ├── 操作区: 新增模板按钮
      ├── 表格区: 模板列表
      │   ├── 列: 模板名称 | 关联场景 | 当前活跃版本 | 更新时间 | 操作(查看版本/编辑)
      └── 详情页 (点击模板名称进入)
          ├── 面包屑导航: 提示词模板 > [模板名称]
          ├── 版本时间线 (左侧)
          ├── 版本内容对比区 (右侧, diff视图)
          ├── 操作: 创建新版本 | 回滚到指定版本
          └── 弹窗: 新增版本
```

**表格列详细规格:**

| 列名 | 宽度 | 对齐 | 说明 |
|------|------|------|------|
| 配置名称 | flex-1 | 左对齐 | 加粗显示 `font-medium text-neutral-800` |
| 模型 | w-40 | 左对齐 | 等宽字体 `font-mono text-xs` 显示模型名 |
| Base URL | w-52 | 左对齐 | 截断显示 `truncate`, hover 全文 |
| API Key | w-36 | 左对齐 | 掩码显示如 `sk-***a3f2`, 等宽字体 |
| Temperature | w-16 | 居中 | 数值, 1位小数 |
| Max Tokens | w-20 | 居中 | 数值 |
| 状态 | w-16 | 居中 | Toggle 开关 (绿色启用/灰色禁用) |
| 当前使用 | w-20 | 居中 | 绿色勾号图标或空 |
| 操作 | w-20 | 居中 | 编辑(铅笔) + 删除(垃圾桶) ghost 按钮 |

## 三、用户操作流程

### 3.1 模型配置管理流程

```
用户进入页面
    │
    ├── 选择 "模型配置" Tab
    │       │
    │       ├── 查看模型配置列表
    │       │       │
    │       │       ├── 点击 [新增配置]
    │       │       │       │
    │       │       │       ├── 填写表单 (配置名、模型、Base URL、API Key、参数)
    │       │       │       │       │
    │       │       │       │       ├── 点击 [创建] ──→ 验证 ──→ 保存成功 ──→ 列表刷新
    │       │       │       │       │       │
    │       │       │       │       │       └── 验证失败 ──→ 显示错误提示 ──→ 聚焦错误字段
    │       │       │       │       │
    │       │       │       │       └── 点击 [取消] ──→ 关闭弹窗
    │       │       │       │
    │       │       │       └── 关闭弹窗 (X 按钮 / ESC / 遮罩点击) ──→ 无保存直接关闭
    │       │       │
    │       │       ├── 点击 [编辑] (铅笔图标)
    │       │       │       │
    │       │       │       ├── 打开编辑弹窗 (预填已有数据)
    │       │       │       │   API Key 字段显示 placeholder: "留空则保持原值"
    │       │       │       │       │
    │       │       │       │       ├── 修改后点击 [保存] ──→ 验证 ──→ 保存成功 ──→ 列表刷新
    │       │       │       │       └── 点击 [取消] ──→ 关闭弹窗
    │       │       │       │
    │       │       │       └── 关闭弹窗
    │       │       │
    │       │       ├── 点击 [删除] (垃圾桶图标)
    │       │       │       │
    │       │       │       ├── 弹出确认弹窗: "确定删除配置 [名称]？此操作不可恢复。"
    │       │       │       │       │
    │       │       │       │       ├── 点击 [确定删除] ──→ 删除成功 ──→ 列表刷新
    │       │       │       │       └── 点击 [取消] ──→ 关闭确认弹窗
    │       │       │       │
    │       │       │       └── 若删除的是"当前使用中"配置 ──→ 额外警告
    │       │       │           "该配置为当前使用中，删除后将无可用配置。确定继续？"
    │       │       │
    │       │       ├── 点击 Toggle 开关 (启用/禁用)
    │       │       │       │
    │       │       │       ├── 启用 ──→ 立即生效，无确认弹窗
    │       │       │       └── 禁用 ──→ 若为"当前使用中" ──→ 警告弹窗
    │       │       │
    │       │       └── 点击"当前使用"列的勾号
    │       │               │
    │       │               ├── 弹出确认弹窗:
    │       │               │   "将 [配置名称] 设为当前使用配置？\n当前使用: [旧配置名称]"
    │       │               │       │
    │       │               │       ├── 确认 ──→ 切换成功 ──→ 列表刷新
    │       │               │       └── 取消 ──→ 无操作
    │       │               │
    │       │               └── 该配置必须处于启用状态才能设为当前使用
    │
    └── 初始加载
            │
            ├── 显示 skeleton loading
            │
            ├── 加载成功 ──→ 渲染列表
            │
            └── 加载失败 ──→ 显示错误提示 toast ──→ 提供重试按钮
```

### 3.2 Token 统计查看流程

```
用户选择 "Token 统计" Tab
    │
    ├── 加载统计卡片数据 + 图表数据
    │       │
    │       ├── 加载中 ──→ skeleton loading (复用现有模式)
    │       │
    │       ├── 加载成功
    │       │       │
    │       │       ├── 渲染 4 张 gradient-card (带入场动画, stagger delay)
    │       │       │
    │       │       ├── 渲染趋势折线图
    │       │       │       │
    │       │       │       ├── 默认显示 7 天数据
    │       │       │       │
    │       │       │       ├── 点击 [30天] ──→ 切换为 30 天数据
    │       │       │       │       │
    │       │       │       │       └── 带过渡动画切换图表
    │       │       │       │
    │       │       │       └── hover 折线点 ──→ tooltip 显示日期 + 具体数值
    │       │       │
    │       │       └── 渲染模型分布图
    │       │               │
    │       │               ├── hover 扇区 ──→ 高亮 + tooltip 显示模型名 + 占比
    │       │               │
    │       │               └── 点击扇区 ──→ 展开该模型详情 (可选)
    │       │
    │       └── 加载失败 ──→ 显示空状态 + 重试按钮
```

### 3.3 提示词模板版本管理流程

```
用户选择 "提示词模板" Tab
    │
    ├── 查看模板列表
    │       │
    │       ├── 点击 [新增模板]
    │       │       │
    │       │       ├── 填写表单 (模板名称、关联场景、初始内容)
    │       │       │       │
    │       │       │       ├── 保存成功 ──→ 自动创建 v1 版本 ──→ 列表刷新
    │       │       │       └── 验证失败 ──→ 显示错误
    │       │       │
    │       │       └── 关闭弹窗
    │       │
    │       ├── 点击模板名称 (进入版本管理详情)
    │       │       │
    │       │       ├── 页面切换为版本详情视图
    │       │       │       │
    │       │       │       ├── 左侧: 版本时间线
    │       │       │       │       ├── 每个版本节点显示: 版本号、时间、创建者、备注
    │       │       │       │       ├── 当前活跃版本用绿色圆点高亮
    │       │       │       │       └── 非当前版本显示 [回滚] 按钮
    │       │       │       │
    │       │       │       ├── 右侧: 版本内容对比
    │       │       │       │       ├── 默认显示当前版本内容
    │       │       │       │       ├── 可选择两个版本进行对比
    │       │       │       │       │       │
    │       │       │       │       │       ├── 并排对比模式
    │       │       │       │       │       └── 差异对比模式 (绿色新增/红色删除)
    │       │       │       │       └── 右下角: 版本元信息 (创建者、备注)
    │       │       │       │
    │       │       │       ├── 点击 [创建新版本]
    │       │       │       │       │
    │       │       │       │       ├── 打开弹窗: 编辑提示词内容
    │       │       │       │       │   ├── 顶部: 版本号自动递增 (v4 → v5)
    │       │       │       │       │   ├── textarea: 提示词内容 (预填当前版本内容)
    │       │       │       │       │   └── 备注输入框 (可选)
    │       │       │       │       │
    │       │       │       │       ├── 保存成功 ──→ 新版本创建 ──→ 时间线更新
    │       │       │       │       └── 保存失败 ──→ 显示错误
    │       │       │       │
    │       │       │       └── 点击版本节点的 [回滚] 按钮
    │       │       │               │
    │       │       │               ├── 弹出确认弹窗:
    │       │       │               │   "确定回滚到 v2？\n将基于 v2 的内容创建新版本 v5 作为当前活跃版本。\n原始版本历史将被保留。"
    │       │       │               │       │
    │       │       │               │       ├── 确认回滚 ──→ 创建新版本 (基于旧版本内容) ──→ 列表更新
```

```typescript
// ── 大模型配置 ──
export interface LlmConfig {

  timeout: number           // 超时时间(秒)

  is_current: boolean       // 是否为当前使用配置
  created_at: string
  updated_at: string
}

export interface TokenStats {
  total_tokens: number      // 总消耗 token 数
  today_tokens: number      // 今日消耗
  total_calls: number       // 总调用次数
  avg_tokens_per_call: number // 平均每次调用 token 数
}

export interface TokenTrend {
  date: string              // 日期 YYYY-MM-DD
  tokens: number            // 当日消耗
  calls: number             // 当日调用次数

  model_name: string        // 模型名称
```

| Tab vs 垂直滚动 | **Tab 切换** | 三个区块功能独立，Tab 避免页面过长 |
| API Key 编辑策略 | **留空保持原值** | 避免每次编辑都需重新输入，降低误操作风险 |
| 回滚策略 | **基于旧版本创建新版本** | 保留完整历史，避免覆盖，审计可追溯 |
| 图表库 | **ECharts** (复用现有) | 与 AnalyticsView 保持技术栈一致 |
| 版本对比 | **并排 + 差异双模式** | 并排适合查看整体，差异适合精准定位改动 |
| 当前使用切换 | **单选互斥** | 同时只有一个活跃配置，简化运维 |
| 弹窗宽度 | **640px (配置) / 520px (模板)** | 与现有 MajorView (640px) 和 RegionView (480px) 对齐 |
